# myagentskills

A collection of agent skills for Claude Code and other coding agents.

## Install

Install skills from this repo with the [`skills`](https://github.com/vercel-labs/skills) CLI:

```sh
npx skills add kBashar/myagentskills
```

The command lists the available skills. Select the skills and the agents you want.

Install one skill directly:

```sh
npx skills add kBashar/myagentskills -s ghissue
```

Install all skills for all agents:

```sh
npx skills add kBashar/myagentskills --all
```

Add `-g` to install at the user level instead of the project level.
